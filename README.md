# Olymp Helper — База законів і помічник фракцій

Десктопний лаунчер і внутрішньоігровий оверлей для гравців державних фракцій (GTA V / RAGE / MTA).
Мова інтерфейсу — українська. Побудовано на **Tauri 2** (Rust + WebView2), без Python і без серверної частини.

## Можливості

- **Лаунчер:** новини, кнопки ресурсів (Discord, форум, сайт, таблиці), банер проєкту, налаштування.
- **Оверлей:** окреме прозоре вікно поверх гри, що відкривається й ховається глобальною гарячою клавішею.
- **База законів:** живий пошук за статтею, назвою, описом і тегами (`Ctrl + K`).
- **Калькулятор покарань:** обираєте кілька статей і одразу бачите загальний штраф, час у КПЗ та рівень розшуку (до 5 ★).
- **Синхронізація:** база завантажується з GitHub під час запуску, кнопка «↻ Оновити базу», офлайн-режим із кешу.
- **Відстеження гри:** лаунчер кожні 3 секунди перевіряє, чи запущений процес гри, і показує статус.
- **Налаштування:** шлях до `.exe` гри, гаряча клавіша, прозорість оверлею, розмір шрифту, автозапуск з Windows.

## Вимоги для збірки (Windows 10/11)

1. [Node.js 18+](https://nodejs.org)
2. [Rust](https://rustup.rs) (stable, MSVC)
3. **Visual Studio Build Tools** з компонентом «Desktop development with C++»
4. WebView2 Runtime (на Windows 11 уже встановлений)

## Запуск і збірка

```bash
npm install
npm run dev        # запуск для розробки (без обфускації)
npm run build      # готовий інсталятор: src-tauri/target/release/bundle/nsis/*.exe
```

Першу збірку Rust компілює кілька хвилин, наступні швидші.

## Налаштування адміністрацією

У збірку вшита лише адреса **маніфесту**. Відкрийте `src/config.js` і замініть адреси (вони вказують на ваш репозиторій із законами):

```js
const MANIFEST_URL    = "https://raw.githubusercontent.com/your-org/gov-laws/main/manifest.json";
const DEFAULT_LAWS_URL = "https://raw.githubusercontent.com/your-org/gov-laws/main/laws.json";
```

Далі все керується файлами в GitHub-репозиторії **без перевипуску лаунчера**. Приклади лежать у `docs/examples/`:

| Файл | Що змінює |
|---|---|
| `manifest.json` | адреса `laws.json` і `news.json`, кнопки ресурсів, банер |
| `laws.json` | категорії та статті (структура з прикладу) |
| `news.json` | стрічка новин (останні 10 записів) |

Поля статті: `id`, `number`, `title`, `description`, `fine`, `jail_minutes`, `wanted_level` (0–5), `bail`, `tags`.
- `bail`: ціна застави числом, наприклад `8000`. Якщо застави немає, пишіть `null`. Для статей без КПЗ (`jail_minutes: 0`) поле не враховується.
- Калькулятор складає суму застав. Якщо хоча б одна з обраних статей без застави, загальна застава показується як «Немає».
- Ліміт КПЗ задається в корені `laws.json`: `"limits": { "max_jail_minutes": 60 }`. Загальний термін у калькуляторі не перевищує цього значення.
Запис у репозиторій мають лише ті, кому ви дали доступ, тож саме він визначає, хто може змінювати закони.
Не забудьте збільшувати `version` та `updated_at` у `laws.json`.

Якщо репозиторій приватний або ви використовуєте не `raw.githubusercontent.com`, додайте новий домен до `connect-src` у `src-tauri/tauri.conf.json`.

## Як працює оверлей

- Оверлей — це **окреме вікно** без рамки, прозоре й завжди поверх інших. У гру нічого не впроваджується.
- Гаряча клавіша глобальна: спрацьовує, навіть коли фокус у грі. Типова — `F5`. Змінюється в «Налаштуваннях»,
  формат комбінацій: `Ctrl + Space`, `Shift + Tab`, `Alt + G`.
- Вікно можна перетягувати за верхню панель. `Esc` ховає оверлей.
- **Два режими запуску.** Кнопка «Запустити оверлей» питає, як відкрити базу законів:
  **як оверлей** (прозоре вікно без рамки поверх гри) або **як окремий застосунок** (звичайне вікно з рамкою
  в панелі завдань, яке можна згортати й розтягувати). Позначте «Запам’ятати вибір», щоб більше не питати.
  Змінити це можна в «Налаштуваннях» → «Запуск оверлею». Гаряча клавіша відкриває вікно в останньому обраному режимі.
- **Важливо:** оверлей видно лише коли гра працює у **віконному** або **віконному без рамки** режимі.
  Поверх справжнього ексклюзивного повноекранного режиму DirectX жодне стороннє вікно не показується.
- Прозорість і розмір шрифту застосовуються до оверлею одразу.

## Система оновлень

Оновлення поділені на три рівні, щоб гравцям не доводилося щоразу завантажувати застосунок.

| Що змінилося | Як доставляється | Чи потрібен реліз |
|---|---|---|
| Закони, новини, посилання, банер, тема, текст Міранди | Лаунчер сам підтягує зміни з GitHub (`laws.json`, `news.json`, `manifest.json`) | Ні |
| Код застосунку (інтерфейс, нові функції, виправлення) | Вбудований оновлювач Tauri: перевіряє нову версію, завантажує **підписане** оновлення з прогресом, встановлює й перезапускає | Так, але лише тег у Git |
| Критичне оновлення | У `manifest.json` вказуєте `"min_launcher": "1.2.0"`: старіші версії бачать червоне повідомлення про обов’язкове оновлення | Так |

Оновлювач Tauri завантажує **весь інсталятор** (кілька мегабайтів для застосунку на Rust), а не окремі змінені файли.
Таких «дельта-оновлень» Tauri не підтримує, але за цієї ваги пакета це майже непомітно. Найчастіші зміни (закони, новини)
взагалі не потребують нової версії.

### Одноразове налаштування

1. Згенеруйте ключ підпису: `npx tauri signer generate -w olymp.key`. Збережіть файл у безпечному місці.
   **Втрата ключа означає, що вже встановлені копії більше не зможуть оновлюватися.**
2. Публічний ключ із виводу команди вставте в `src-tauri/tauri.conf.json` → `plugins.updater.pubkey`.
3. У тому ж файлі замініть `your-org/olymp-helper` в `endpoints` на свій репозиторій.
   Репозиторій має бути **публічним**, бо оновлювач не авторизується.
4. У GitHub → Settings → Secrets додайте `TAURI_SIGNING_PRIVATE_KEY` (вміст `olymp.key`) і, якщо задавали,
   `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`.

### Випуск оновлення

1. Збільште версію у трьох файлах: `package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`.
2. Закомітьте й поставте тег: `git tag v1.2.0 && git push origin v1.2.0`.
3. GitHub Actions (`.github/workflows/release.yml`) збере інсталятор, підпише його, створить реліз і файл `latest.json`.
4. Опис релізу стає текстом повідомлення в лаунчері. Гравці бачать банер «Доступна нова версія» протягом кількох секунд після запуску
   або за кнопкою «Перевірити оновлення» в налаштуваннях.

Локальна збірка (`npm run build`) працює без ключа: підпис потрібен лише для релізів.
Якщо реліз вийшов невдалим, видаліть його на GitHub: `latest.json` знову вкаже на попередню стабільну версію.

## Що нового у версії 1.2

- **Кодекси у вигляді згортних карток:** бейдж-абревіатура, назва, лічильник статей (`158 ст.`) і стрілка. Під час пошуку
  картки з результатами відкриваються самі, а лічильник показує `3 з 158`.
- **Будь-які кодекси, розділи й статті.** Усе береться з `laws.json`. Категорія може мати `articles` і/або `sections`
  (розділи з назвою та власними статтями). Абревіатуру задає поле `abbr`, а якщо його немає, вона береться з дужок у назві
  (`Кримінальний Кодекс (КК)`) або утворюється з перших літер.
- **Довідник (FAQ):** файл `faq.json` (приклад у `docs/examples/`). Це список питань із полями `id`, `question`, `answer`, `tags`.
  Теги й категорії будуються автоматично з даних. Є пошук, фільтр за кількома тегами та кнопка «Копіювати відповідь».
  Адресу файлу задає `faq_url` у `manifest.json`. Без інтернету працює кеш.
- **Нотатки:** автозбереження, створення, редагування, видалення (з підтвердженням) і копіювання в один клік.
  Зберігаються локально в зашифрованому вигляді (AES-GCM). Доступні також в оверлеї.
- **Оверлей** має вкладки «Закони», «Довідник», «Нотатки».
- **Нижня панель** на всіх сторінках: `Olymp Helper | Author: Sanchos` і кнопка «Знайшли баг? / Підтримка» ведуть у Telegram.
  Адреса каналу задається в `src/config.js` (`TG_URL`).
- **Акцентний колір:** у «Налаштуваннях» → «Вигляд» (готові кольори або власний). Вибір гравця має пріоритет над кольором із `manifest.json`.
- Налаштування, які раніше були в `src/app.js` (адреси), перенесено в `src/config.js`, щоб оновлення коду їх не перезаписували.

## Системний трей

- Іконка Olymp Helper з’являється біля годинника. Меню: **«Відкрити Olymp Helper»**, **«Показати/сховати оверлей (F5)»**
  (клавіша в назві оновлюється, якщо ви змінили її в налаштуваннях) і **«Вийти»**. Подвійний клік по іконці відновлює головне вікно.
- Після запуску оверлею в будь-якому режимі головне вікно **ховається в трей**, а застосунок працює у фоні й реагує на гарячу клавішу.
- Кнопка закриття (✕) на головному вікні повністю завершує програму. Закриття вікна оверлею лише ховає його.

## Пошук і продуктивність

- Під час завантаження бази будується локальний індекс (номер, назва, опис, теги, категорія). Пошук `Ctrl + K`
  розбиває запит на слова й показує статті, що містять усі слова. Список не перебудовується, а лише приховує зайве.
- Групи законів згортаються й розгортаються клацанням по заголовку категорії.
- Повзунок масштабу шрифту (80–150 %) змінює весь інтерфейс, включно з розмірами панелей, у лаунчері й в оверлеї.
- Моніторинг гри перевіряє процес кожні 2 секунди. У налаштуваннях можна вказати ім’я процесу (`GTA5.exe`)
  або повний шлях до `.exe` (тоді додатково звіряється розташування файлу).

## Тема й Міранда від адміністрації

У `manifest.json` можна задати `theme.accent` (фірмовий колір сервера, формат `#rrggbb`) та текст `miranda`.
Кнопка «Правило Міранди» у калькуляторі показує цей текст і копіює його. Це звичайний текст для зачитування, без RP-команд.

## Захист даних

- Під час `npm run build` JavaScript обфускується (`javascript-obfuscator`), CSS і HTML мінімізуються,
  а Rust-частина компілюється у бінарний код. Файли `src/` в інсталятор не потрапляють.
- Кеш законів і маніфесту зберігається зашифрованим алгоритмом **AES-GCM**. Якщо користувач змінить кеш вручну,
  розшифрування не вдасться, і застосунок завантажить свіжі дані.
- Ключ кешу вшитий у застосунок. Це захист від випадкового чи ручного редагування, а не від досвідченого
  зловмисника. Надійного захисту клієнтського коду не існує, тому довіряти слід даним з репозиторію, а не кешу.
- Посилання відкриваються лише за схемою `https://`.

## Структура проєкту

```
src/                 фронтенд (HTML, CSS, JS)
scripts/             збирання фронтенду та обфускація
src-tauri/           Rust-частина: вікна, гаряча клавіша, процеси, автозапуск
docs/examples/       приклади manifest.json, laws.json, news.json
app-icon.png         вихідна іконка (можна замінити: npx tauri icon app-icon.png)
```

## Поширені проблеми

- **Гаряча клавіша не спрацьовує:** її вже використовує інша програма. Оберіть іншу комбінацію.
- **Оверлей не видно в грі:** перемкніть гру на віконний режим без рамки.
- **«Гру не запущено»:** перевірте назву процесу в налаштуваннях (наприклад, `GTA5.exe`, `ragemp_v.exe`, `gta_sa.exe`).
- **Помилка збірки на Windows:** переконайтеся, що встановлено Build Tools з компонентом C++.
