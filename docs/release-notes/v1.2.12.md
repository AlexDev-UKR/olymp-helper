Olymp Helper 1.2.12: чистіше вітання, текст кодексів можна виділяти й копіювати

- Вікно вітання: кнопка «Розпочати» без зайвих рамок.
- Головне вікно: бокове меню коректно займає місце з першого показу; сповіщення більше не перекривають кнопки допомоги.
- Лаунчер плавно з'являється з трею, коли ви вимикаєте оверлей.
- «Кодекси та Закони»: можна виділяти й копіювати будь-які фрагменти тексту, копіювати всю статтю або окремий пункт, збіги пошуку підсвічуються.
- Оновлено інсталятор: установка для поточного користувача без прав адміністратора, чистіші метадані, контрольні суми релізу.
